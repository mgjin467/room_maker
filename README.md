# 방 가구 배치 3D 시뮬레이터 (v3 · 클라우드 + AI)

Vite + three.js(0.128) + Firebase. 이전 버전에서 브라우저에 저장된 배치는 자동으로 새 형식으로 옮겨집니다.

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/
vercel --prod
```

## 1. 클라우드 저장 설정 (Firebase · Firestore `room-maker`)
1. **웹 앱 설정 받기** — Firebase 콘솔 → ⚙ 프로젝트 설정 → 일반 → 내 앱 → `</>`(웹 앱 추가) → 표시되는 `firebaseConfig` 코드를 복사
2. **앱에 넣기** — 둘 중 하나
   - 앱의 **저장(☁) 탭**에 코드를 그대로 붙여 넣고 ‘설정 저장 후 연결’
   - 또는 `.env.example`을 참고해 Vercel 환경 변수(`VITE_FIREBASE_*`)로 등록 후 재배포
3. **로그인 방법 켜기** — Authentication → 로그인 방법 → **Google**, **이메일/비밀번호** 사용 설정
4. **도메인 허용** — Authentication → 설정 → 승인된 도메인 → Vercel 주소(예: `xxx.vercel.app`) 추가
5. **보안 규칙 게시** — Firestore → `room-maker` → 규칙 탭에 아래를 붙여 넣고 ‘게시’

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

저장 구조: `users/{uid}/projects/*` (프로젝트), `users/{uid}/meta/settings` (내 크기·내 가구), `users/{uid}/meta/aikeys` (AI 키), `users/{uid}/meta/aimodels` (모델 선택), `users/{uid}/gallery/*` (AI 렌더 이미지). 로그인하지 않으면 브라우저에만 저장됩니다.

## 2. AI 설정
AI 탭 → ⚙ AI 설정 → 키 입력(또는 `geminiApiKey, AIza…` 형식 그대로 한 번에 붙여넣기) → 저장. 로그인 상태면 클라우드에 저장·삭제·업데이트됩니다. API 키는 코드에 넣지 않습니다(공개 사이트 번들에 넣으면 누구나 볼 수 있음).

## 3. AI 기능
- **대화 명령** (음성 입력·사진 첨부 가능): “창가에 몬스테라 추가”, “책장1을 120×30×180 월넛 3열 서랍형으로”, “조명1, 2, 5, 7 완전 어둡게”, “전체 조명 어둡게”, “북유럽 스타일로”, “동선 분석해줘”, “예상 가격 채워줘” … 실행 결과는 한 번에 되돌릴 수 있음
- **사진 → 가구**: 상세페이지·치수표 사진에서 품목·사이즈(mm→cm)·형태(서랍형/도어형, 열 구성)를 인식, 여러 사이즈는 선택
- **사진 → 사람**: 사진 속 사람을 한 명씩 3D 사람으로 (기본 남 180 / 여 165cm, 사진 키 비율 반영 옵션)
- **방·도면 사진 → 방 크기·창호·가구**
- **실사 렌더**: 유튜브·쇼츠·모바일 세로/가로·PC·울트라와이드·인스타·A4 등 크기 × 여러 각도(눈높이 모서리 시점 포함) × 스타일, 배치·크기·재질·조명 밝기 설정을 그대로 반영. AI 없이 고화질 캡처도 가능

## 모든 기기에서 바로 로그인 (Firebase 설정 내장)

Firebase 웹 설정(apiKey, appId 등)은 **공개용 값**이라 앱에 넣어도 됩니다. (보안은 Firestore 규칙 + Authentication 「승인된 도메인」이 담당)
한 번 넣어 두면 PC·휴대폰 어디서든 처음부터 「Google 로그인」 버튼이 보이고, 로그인하면 그 계정의 프로젝트·내 가구·AI 키가 자동으로 적용됩니다.

방법 (셋 중 하나):
1. **src/firebase.config.js** 에 값 붙여 넣고 재배포 — 설정된 PC에서 저장 탭 → 「Firebase 설정 변경 · 설정 파일 코드」 → 「설정 파일 코드 복사」로 파일 내용을 그대로 복사할 수 있음
2. **Vercel 환경변수** `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_APP_ID` … (.env.example 참고) 후 재배포
3. 재배포 없이 바로: 설정된 PC 저장 탭 → **「📱 다른 기기 연결 (QR)」** → 휴대폰 카메라로 QR 찍기

※ AI API 키는 절대 firebase.config.js 에 넣지 마세요. 로그인 후 ⚙ AI 설정에서 저장하면 클라우드(users/{uid}/meta/aikeys)에 저장되어 다른 기기에서 로그인 시 자동으로 불러옵니다.

## 러그 · 실사 왜곡 방지 · 대화창
- 러그: 모양 6종(직사각·원형·타원·육각·팔각·반달) × 무늬 30종(페르시안·빈티지·오리엔탈·킬림·베니 오레인·트렐리스·기하학·스트라이프·쉐브론·헤링본·체크·타탄·추상·컬러블록·만다라·플라워·테라조·호피·카우하이드·샤기·황마·루프 등) + 색 3개 + 무늬 크기 · 카탈로그 러그 프리셋 42종 · 「실제 러그 사진으로 무늬 입히기」(사진 그대로 텍스처, 실사 렌더에도 참고 사진으로 전달)
- 창호 유리 투명도(0~100%)·유리 색(클리어·저철분·브론즈·그레이·블랙·반투명·간유리)
- 실사 변환 왜곡 방지(「🧭 구조 고정」 기본 켜짐): 같은 카메라로 렌더한 색 구분 구조 가이드(창=파랑, 문=주황, 가구=고유색)를 함께 보내고, 창호마다 벽(앞/뒤/좌/우·전경 여부)·폭 비율·창턱 높이·화면 속 위치(%)를 프롬프트에 명시. OpenAI 편집은 input_fidelity=high
- 이미지 AI 안전 필터가 일반 장면을 잘못 거절하면: 사람 묘사 단순화 → 사람 제외 → 다른 이미지 AI 순으로 자동 재시도 (필터 우회가 아니라 오탐 회피)
- 대화 입력창 확대, 입력창·대화창 높이 끌어서 조절(모바일 포함, 더블클릭 시 기본 크기)
- 알림 배너: 실사 이미지 완성(보기), AI 대화 적용(되돌리기), 사진 인식 완료, 참고 사진 적용, 저장·삭제·오류 등 모든 작업 결과가 화면 위쪽 배너로 표시 (✓ 초록 = 완료, ! 빨강 = 오류). 앱이 백그라운드에 있으면 브라우저 알림(권한 허용 시)
- 이미지 안전 필터 오탐 대응(apiyi 이미지 안전 문제 해결 문서 참고): 사람마다 옷차림·색을 명시, 오해 소지 형용사 제거, 결과 이미지 단계 거절(20초 이상 걸린 400)은 같은 내용으로 1회 재시도, OpenAI 공식 moderation=low 파라미터
- 야외 안의 집: 야외 공간을 추가할 때 「전체 집 / 특정 방 / 배치 안 함」 선택(기본: 전체 집). 이 프로젝트의 방 공간이 창호·가구 그대로 건물로 놓이고, 끌어서 이동·회전, 지붕(평지붕·박공·없음), 더블클릭 또는 「이 방으로 들어가기」로 그 방 편집. 방을 고치면 야외에도 반영. 방·창호 탭(야외) 「🏠 집·방 배치」에서 추가·제거
- AI 키: 새 Google 키 형식(AQ.…) 지원, Gemini 키는 x-goog-api-key 헤더로 전송. 공급자마다 키를 여러 개(한 줄에 하나) 넣으면 크레딧 소진(402)·한도 초과(429)·잘못된 키(401/403) 때 자동으로 다음 키 사용. 「🔌 키별 연결 확인」으로 키마다 상태 확인. 모델 gemini-flash-latest / pro-latest / flash-lite-latest 추가(기본 대화·인식 모델 = gemini-flash-latest). 모델 ID 직접 입력도 가능
- 🏘 모든 공간 함께 보기: 배경 야외(없으면 자동 생성) 위에 모든 방을 배치. 방 끌기 시 다른 방 벽에 자동으로 붙음(30cm), 선택 탭 「🧲 다른 공간에 붙이기」(오른쪽/왼쪽/앞/뒤 · 정렬 · 맞닿은 벽에 문). 「🔗 연결 통로」: 일자·ㄱ자 통로 + 양쪽 방 벽에 개구부/문 자동 생성(기존 창호를 피해서 배치, ◀ ▶로 이동), 방을 옮기면 통로·문이 따라감. 방 안에서도 옆방·통로·야외 풍경이 보임(☰ 「옆 공간·야외 배경 함께 보기」), 옆방 더블클릭 → 이동
- 창문·문·조명 클릭 선택 끄기: ☰ 메뉴 / 방·창호 탭 / 선택한 창호의 「🚫 … 클릭 선택 끄기」 — 끄면 클릭이 뒤의 가구로 감 (목록에서는 계속 선택 가능)

## 전체 화면 이미지 보기
- 실사 결과·갤러리·참고 사진·저장 미리보기 이미지를 누르면 화면을 꽉 채우는 전체 화면 뷰어로 열립니다.
- 닫기: ✕ 버튼, 화면 탭/클릭, Esc, 모바일 뒤로가기.
- 확대: 두 손가락 핀치·두 번 탭(모바일), 마우스 휠(PC). 확대 중엔 드래그로 이동.
- 세로 화면에서 가로 이미지는 「⟳ 가로로」로 90° 돌려 꽉 차게 볼 수 있고, 기기를 가로로 돌리면 자동으로 다시 맞춥니다.
