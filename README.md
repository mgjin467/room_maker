# 방 가구 배치 3D 시뮬레이터 (v2)

Vite + three.js(0.128.0) 프로젝트입니다. 기존 버전(v1)에서 브라우저에 저장된 배치는 처음 실행할 때 자동으로 '내 방' 프로젝트로 옮겨집니다.

## 로컬 실행
```bash
npm install
npm run dev        # http://localhost:5173
```

## 빌드 / Vercel 배포
```bash
npm run build && npm run preview
vercel --prod      # 또는 GitHub 연동 후 Import (Build: npm run build, Output: dist)
```

## 주요 기능
### 가구·소품 (150종 이상)
- 거실 · 침실 · 주방·다이닝 · 서재·사무 · 수납 · 스탠드·조명 · 식물·화분(20종) · 데코·소품 · 가전·생활
- 검색, 최근 사용, **내 가구 등록**(선택한 가구를 카탈로그에 저장)
- 모델(모양) 변경, 색상/보조색, 설치 위치(바닥·벽 부착·천장 매달기), 소품 자동 올리기(책상 위 모니터 등)

### 크기 조절
- cm 입력, 가로/세로/높이 **% 입력**, 전체 % 슬라이더, 빠른 % 버튼(50~200%, ±5%)
- **비율 유지 / 해제** 토글 (3D 화면의 파란 점: 가로·세로, 주황 화살표: 높이 드래그)
- **사용자 크기 기억**: 크기를 바꾸면 해당 가구의 '내 크기'로 저장되어 다음에 추가할 때 자동 적용 (카탈로그에 ● 표시). '기본 크기로', '같은 종류 모두 이 크기로' 지원

### 방·창호·조명
- 방 크기: 숫자 입력 또는 벽 바깥 **주황 핸들 드래그** (4면 모두)
- 창문 7종 / 문 9종(여닫이·양개·미닫이·3연동 중문·원슬라이딩·유리 중문·폴딩·현관문·개구부)을 원하는 벽에 추가·삭제, **벽을 따라 드래그**(모서리를 넘기면 옆 벽으로), 창문은 Shift+드래그로 높이
- 프레임·문짝 색, 유리, 경첩/열림 방향/열림 각도, 커튼·블라인드·롤스크린
- 천장·벽 조명 12종(다운라이트, 평판등, 방등, 펜던트 3종, 샹들리에, 레일, 실링팬, 벽등, 간접조명), 색온도·밝기, 드래그 이동, **야간 모드**
- 바닥재 8종, 벽 색/포인트 벽, 걸레받이 색

### 실무 기능
- 겹침 · 창문 가림 · 문 열림 간섭 자동 경고, 주변 간격 치수(60cm 미만 빨간색), 줄자 측정
- 되돌리기/다시 실행(Ctrl+Z / Ctrl+Y), 복사·붙여넣기, 잠금, 스냅(그리드·벽·가구 모서리)
- 여러 프로젝트 자동 저장, JSON 내보내기/가져오기, CSV(엑셀) 가구 목록·견적, 3D 화면 PNG, 2D 평면도 PNG, 평면도+목록 인쇄(PDF)
- 시점: 입구·대각선·위에서·**평면도(직교 2D)**, 더블클릭/F 키로 선택 대상 확대

## 단축키
| 키 | 동작 |
|---|---|
| 방향키 (Shift 20cm / Alt 1cm) | 이동 (기본 5cm) |
| R / Shift+R | 90° / 15° 회전 |
| [ / ] | 5% 작게 / 크게 |
| PageUp / PageDown | 바닥에서 높이 |
| Delete | 삭제 |
| Ctrl+D / Ctrl+C / Ctrl+V | 복제 / 복사 / 붙여넣기 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 실행 |
| F, 더블클릭 | 선택 대상으로 카메라 이동 |
| Esc | 선택 해제 / 줄자 종료 |

## 구조
- `index.html` : 화면 뼈대
- `src/main.js` : 상태·저장·편집·드래그·UI
- `src/catalog.js` : 가구 카탈로그 (이름, 크기, 색, 모델, 옵션) — 여기에 줄을 추가하면 카탈로그에 바로 나타납니다
- `src/builders.js` : 가구 3D 모델
- `src/fixtures.js` : 창문·문·조명 3D 모델
- `src/plan.js` : 2D 평면도 그리기
- `src/style.css` : 스타일
